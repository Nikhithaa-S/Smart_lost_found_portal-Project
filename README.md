# Smart_lost_found_portal-Project

## 1. Overview
CampusFind is a web-based Lost and Found Management System designed for college campuses. It helps students and staff report lost items and post details of items they have found. Users can search for missing belongings, view item details, and submit claim requests to recover their lost items.

The system provides a simple and organized platform to make the process of finding and returning lost belongings easier.

## 2. Objective
The main objectives of CampusFind are:

- To provide a centralized platform for reporting lost and found items.
- To help students easily search for missing belongings.
- To allow users to report items they have found on campus.
- To enable users to submit claim requests for items.
- To reduce the time and effort involved in recovering lost belongings.
- To improve communication and coordination between students and staff.

## 5. How to Run the Project

### Step 1: Clone the Repository

Open the terminal and run:

```bash
git clone https://github.com/Nikhithaa-S/Smart_lost_found_portal-Project.git
```

### Step 2: Open the Project Folder

```bash
cd Smart_lost_found_portal-Project
```

### Step 3: Create a Virtual Environment

```bash
python -m venv venv
```

### Step 4: Activate the Virtual Environment

For Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### Step 5: Install Required Packages

```bash
pip install -r requirements.txt
```

### Step 6: Run the Application

```bash
python app.py
```

### Step 7: Open in Browser

Open your browser and visit:

```text
http://127.0.0.1:5000
```

The CampusFind application will now be available locally.

## 6. Main Features

- **User Registration:** New users can create an account.
- **User Login:** Registered users can securely access the application.
- **Report Lost Items:** Users can report belongings they have lost.
- **Report Found Items:** Users can post information about items they have found.
- **Search Items:** Users can search and view lost and found item listings.
- **Item Details:** Users can view item descriptions, photographs, and locations.
- **Claim Request:** Users can submit a request to claim an item.
